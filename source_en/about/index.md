## About This Site

**CDP Automation Guide** is a technical blog focused on Chrome DevTools Protocol (CDP).

### Why This Site?

CDP (Chrome DevTools Protocol) is Chrome's built-in debugging protocol that powers tools like Puppeteer and Playwright. While the official documentation is comprehensive, practical, hands-on tutorials are scattered. This site aims to fill that gap with systematic, real-world guides.

### What You'll Find

- CDP fundamentals and architecture
- Controlling Chrome with Python via WebSocket
- Browser automation (scraping / RPA / automated testing)
- Anti-detection and fingerprint management
- CDP toolchain development
