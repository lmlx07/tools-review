关于本站

CDP 自动化指南 是一个专注于 Chrome DevTools Protocol（CDP）的中文技术博客。

为什么做这个站？

CDP（Chrome DevTools Protocol）是 Chrome 浏览器内置的调试协议，Puppeteer、Playwright 等工具的底层都是它。但中文资料相对分散，缺少系统的实战教程。这个站的目标就是填补这个空白。

内容方向

  • CDP 基础概念与架构
  • Python 通过 WebSocket 控制 Chrome 实战
  • 浏览器自动化（爬虫 / RPA / 自动化测试）
  • 反检测与指纹管理
  • CDP 工具链开发
